# PetCare

Prototipo web académico desarrollado con HTML, CSS y JavaScript puro.

## Cómo abrirlo

1. Abre la carpeta `PetCare`.
2. Haz doble clic en `index.html`.
3. Usa los botones de acceso rápido para entrar como cliente o prestador.

No requiere instalación ni conexión a una base de datos. Las mascotas, reservas y cambios del perfil se guardan en el almacenamiento local del navegador.

## Pantallas incluidas

1. Inicio de sesión.
2. Registro de usuario.
3. Panel principal.
4. Mis mascotas.
5. Búsqueda de servicios.
6. Detalle del prestador.
7. Reserva del servicio.
8. Confirmación.
9. Mis reservas.
10. Perfil del prestador.
11. Agenda del prestador.
